# AnimalFarm360 

**AnimalFarm360** is a full-stack, role-based e-commerce and farm management web application designed to digitize and streamline the daily operations of livestock and animal product businesses.

The platform provides dedicated portals for customers and administrators, allowing them to manage purchases, products, orders, farm visits and other farm-related operations through a centralized web application.

## Key Features

### Customer Portal
- User registration, login and secure authentication.
- Browse animals and animal-based products.
- Search products and view product details.
- Add products to the shopping cart and place orders.
- View order history and track order status.
- View invoices for individual orders.
- Book farm visits and track approval status.
- Update personal profile information.

### Admin Panel
- Secure admin login and access control.
- Manage animal records (Create, Read, Update, Delete).
- Manage product listings and catalogue.
- View and manage customer orders.
- Update order status.
- Approve or reject farm visit requests.

### Public Pages
- Home
- About Us
- Products
- Contact
- FAQ
- Terms & Conditions
- Privacy Policy
- Cookie Policy
